# Business Forecasting with Python

A self-paced introduction to business forecasting using Google Colab. Start with time-series graphics and decomposition, then practice forecast evaluation, regression, exponential smoothing, and ARIMA.

[Open the website](https://drocsic.github.io/business-forecasting/)

Each module links to Python notebooks and explains which data it uses. The notebooks draw on examples from [Forecasting: Principles and Practice, the Pythonic Way](https://otexts.com/fpppy/). The publisher provides the [textbook datasets](https://otexts.com/fpppy/data/).

This repository contains the public learning materials. The site is served by GitHub Pages from the root of the `main` branch.
